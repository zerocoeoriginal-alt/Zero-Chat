ZeroChat Privacy Policy

Last updated: 21 October 2026

ZeroChat provides direct messaging between users. This policy describes data used to provide the service.

Data used

  • Account identifiers and profile information supplied by the identity provider you choose.
  • Public username, display name, public profile and public device keys needed to find accounts and establish conversations.
  • Message records, timestamps, sender identifiers and conversation identifiers.

How data is used

Data supports sign-in, user discovery, conversation storage and realtime updates. Supabase provides authentication, database and realtime services. Google or Facebook may process sign-in data when you select those providers.

Retention and deletion

Account and conversation data is retained while the account remains active. See the account-deletion page for the deletion process. The publisher must host that page on HTTPS and link it here before release.

Security limitations

The current app design uses device-specific key material. It does not provide forward secrecy, key synchronization across devices, or recovery after loss of local app data. Do not describe these features as supported.

Contact

The publisher must add a public support contact before publishing this policy.
