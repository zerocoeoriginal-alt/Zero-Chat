# Zero-Chat

Android messaging application built with Kotlin and Jetpack Compose, using Supabase for backend services.

## Project structure

- `app/` — Android application source, UI, repositories, and resources.
- `supabase/` — database setup and migrations.
- `docs/` — privacy policy, account deletion, and release notes.

## Setup

See `supabase/SETUP.md` for backend setup instructions. Configure local SDK paths and secrets on your machine; do not commit local configuration or credentials.
